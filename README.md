 ProxiSpeak

ProxiSpeak is a virtual office platform built for natural online collaboration, featuring real-time avatar movement and proximity-based audio. 

 Features

* **Real-Time Avatar Movement:** Move your avatar across the virtual workspace smoothly.
* **Proximity-Based Audio:** Hear and speak only with people who are close to your avatar, mimicking a real office environment.
* **Collaborative Workspace:** Interact with colleagues effortlessly in a spatial digital setup.
* **Database Integration:** Utilizes MongoDB Atlas for persistent data storage.

 Tech Stack

* Frontend: JavaScript, CSS, HTML
* Backend / Database: Node.js, MongoDB Atlas
